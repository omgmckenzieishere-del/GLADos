GLaDOS INSTALLATION

This installer includes:
- GLaDOS.exe
- Still Alive.flac
- A desktop shortcut

Required for AI chat:
1. Install Ollama from https://ollama.com
2. Open Command Prompt and run: ollama pull llama3.2:3b
3. Leave Ollama running while using GLaDOS

Music:
- The included song is in the installed music folder.
- Use "play still alive" in GLaDOS.

The bot does not execute shell commands.
